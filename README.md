## Typing Speed Calculator

A small React app that measures words-per-minute as you type. The UI highlights correct and incorrect characters in real time and stops the timer when you finish the prompt.

### Scripts
- `npm start` — run locally in development mode.
- `npm run build` — create a production build.

### Project structure
- `src/components` — UI building blocks (`Preview`, `Speed`).
- `src/utils` — helpers (`getRandomText`).
- `src/App.js` — main feature logic.
